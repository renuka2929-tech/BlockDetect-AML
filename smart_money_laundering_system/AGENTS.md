## Project Summary
Smart Money Laundering is a high-tech fraud detection and prevention dashboard that leverages AI, Machine Learning, and Blockchain technology to monitor and analyze financial transactions in real-time. The project features advanced visualizations, including 2D and 3D animations, to illustrate the transaction flow and security layers.

## Tech Stack
- **Frontend/UI**: NiceGUI (Python-based UI framework), Tailwind CSS, Plotly.js, Three.js
- **Backend**: Python
- **AI/ML**: Scikit-learn (implied by fraud detection), NumPy, Pandas
- **Blockchain**: Custom immutable ledger implementation (Python)
- **Visualizations**: Plotly for charts, Three.js for 3D simulations

## Architecture
- **app/**: Core application logic
  - `ui.py`: Main UI components and pages
  - `animations_page.py`: Interactive 2D and 3D animation visualizations
  - `ai_engine.py`: Machine Learning logic for fraud detection
  - `blockchain.py`: Immutable ledger implementation
  - `services.py`: Data services and summary logic
- `main.py`: Entry point for the NiceGUI application

## User Preferences
- **Theme**: Cyber/AI/ML-themed UI with neon accents (green, blue, magenta) and dark backgrounds.
- **Interactivity**: High level of interactivity with scroll-triggered animations and hover effects.

## Project Guidelines
- Mimic existing NiceGUI patterns
- Use Tailwind CSS for styling
- Follow the "Cyberpunk/High-Tech" aesthetic
- No comments unless requested

## Common Patterns
- Scroll-triggered animations using Intersection Observer
- Glassmorphism effects for cards
- 3D visualizations using Three.js integrated with NiceGUI
